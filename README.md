# I-wish
Önskelisteapp för barn. Föräldrar klistrar in länkar till kategorisidor i webbutiker
(t.ex. leksaker på clasohlson.com) och väljer ett prisspann. Appen hämtar produkterna
från sidorna, barnet swipar höger på det de önskar sig och får en önskelista med pris
och köplänk.

Se [docs/SPEC.md](docs/SPEC.md) för specifikation och nästa steg.

## Kom igång

```bash
npm install
npx expo start
```

Skanna QR-koden med appen **Expo Go** på mobilen eller surfplattan.

## Kontroller

```bash
npm run typecheck
npm test
```
